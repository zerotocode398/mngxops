# 仪表盘

## 页面与权限

登录后访问 `/` 查看系统概览。统计卡按节点、配置绑定和任务分组；快捷入口与卡片链接仅在当前账号拥有目标模块权限时显示或启用。统计数字沿用参考首页的可见口径，任务数据按任务中心的可见范围计算。

首页通过 `GET /api/stats/` 轮询统计数字。节点统计排除逻辑删除节点；配置统计排除已删除节点上的绑定，待推送合计 `not_synced` 和 `modified`；任务统计只计入任务中心权限允许查看的任务。最近任务使用同一范围、`dashboard.recent_tasks_count` 条数限制及统一任务摘要格式。

任务中心无可见权限时，首页显示空态，运行中和近 7 天任务统计为 0。任务详情链接通过 `/tasks/{task_id}/` 打开，并沿用任务中心的权限与资源隐藏规则。

## 设置

`system.dashboard_refresh_interval` 控制页面统计轮询间隔，默认 30 秒，可设置为 5 至 3600 秒；修改后刷新首页生效。`dashboard.recent_tasks_count` 控制首页及 Nginx 运维首页的最近任务行数，默认 20。

## API

| 方法与路径 | 认证 | 说明 |
|---|---|---|
| `GET /api/stats/` | 登录会话 | 返回节点、配置绑定和当前用户可见任务统计，供首页定时刷新 |

统计接口使用 `DashboardStatsResponse`，不接受请求参数或修改数据。未登录返回公共 `ApiError` 的 401 响应。

## 实现差异

相对 `mngxops`，首页仍保留原统计分组、快捷入口、最近任务摘要和静默轮询；任务权限直接复用当前统一任务中心范围。待推送卡片合并 `not_synced` 与 `modified`，与 NX-032 配置列表的待推送筛选保持一致。节点与配置数字按参考项目展示，卡片跳转仍由对应页面权限控制。
